# IngiGroup WordPress Theme

Классическая многостраничная тема WordPress, разработанная для проекта IngiGroup.

---

## 🛠 AI Context & Architecture Reference
*Этот раздел предназначен для ИИ-ассистентов (Cursor, Copilot, ChatGPT) для быстрого понимания контекста проекта.*

- **Тип темы:** Классическая тема WordPress (PHP / Хуки / Шаблоны)
- **Текстовый домен (Text Domain):** `ingigroup` *(Используй этот слаг во всех функциях локализации `_e()`, `__()`)*
- **Сборщик скриптов:** Отсутствует. Все статичные файлы подключаются напрямую из папки `assets/`.
- **Базовые шаблоны:** Наличие файлов `front-page.php` (главная), `page.php` (внутренние страницы) и `index.php` (резервный шаблон).

### Ключевая структура файлов для ИИ:
- `functions.php` — Точка входа. Здесь регистрируются стили, скрипты, меню и кастомная логика темы.
- `style.css` — Главный файл мета-данных WordPress темы и глобальные стили.
- `inc/` — Директория для модульного PHP-кода (кастомные функции, обработчики форм, хуки, настройки кастомайзера).
- `template-parts/` — Папка для изолированных и переиспользуемых фрагментов разметки (например, циклы постов, компоненты).
- `assets/` — Все публичные ресурсы: подпапки для стилей (`css/`), скриптов (`js/`), изображений (`img/`) и шрифтов.
- `header.php` & `footer.php` — Семантический верх и низ сайта, вызываемые через `get_header()` и `get_footer()`.

## 🚀 Начало работы и Установка

### Локальное окружение
Для работы темы требуется установленный локальный сервер с WordPress (например, Local WP, OpenServer, Docker или Laragon).

### Шаги по установке:
1. Перейдите в директорию с темами вашего WordPress-сайта:
   ```bash
   cd wp-content/themes/
   ```
2. Склонируйте данный репозиторий:
   ```bash
   git clone https://github.com
   ```
3. Перейдите в административную панель WordPress: `Внешний вид` -> `Темы`.
4. Найдите тему **IngiGroup** и нажмите **Активировать**.

## 📂 Правила расширения проекта (Гайдлайн для ИИ)
При генерации нового кода для этой темы строго следуй правилам архитектуры:
1. **Логика отдельно от разметки:** Не пиши массивные функции внутри шаблонов страниц. Выноси логику в виде функций или классов в папку `inc/`, а затем подключай файлы через `require` в `functions.php`.
2. **Переиспользуемый HTML:** Если элемент структуры повторяется (например, карточка товара/новости, кастомный баннер), изолируй его в `template-parts/` и вызывай через функцию `get_template_part('template-parts/имя-файла')`.
3. **Статика:** Скрипты и кастомные стили распределяй строго по соответствующим папкам внутри `assets/`. Подключение новых скриптов делай исключительно через функцию `wp_enqueue_script()` в `functions.php`.
