## 1. Цель

Кастомная WordPress-тема — копия сайта https://ingigroup.ru/ один-в-один, с возможностью создавать и редактировать новые страницы в том же стиле.

Компания «ИНЖИГРУПП» — инжиниринговая (не девелопер). Направления:
- Установка рельсовых страховочных пакетов (РСП)
- Вырубка древесно-кустарниковой растительности (ДКР)
- Общестроительные работы (сети, СМР, настилы)

## 3. Стек

- WordPress, кастомная тема `ingigroup`
- **Плагины:** Rank Math SEO (Free), Autoptimize (для CSS/JS), WP Yandex Metrika (Деактивирован!)
- Шрифт: Inter (Google Fonts), 100–900
- Анимации: AOS + GSAP + ScrollTrigger (грузятся с `defer`)
- Карта: Яндекс.Карты API (главная, «О компании») + iframe map-widget (`/contacts`) с **ленивой загрузкой** (`data-src`)
- Форма: AJAX через `admin-ajax.php` — action `ingi_send`
- Почта: `wp_mail()` → SMTP (письма уходят на `info@ingigroup.ru`)

## 9. Известные грабли (Дополнено)

1. **Кэш:** Ctrl+Shift+R + `filemtime` в `enqueue.php` + Autoptimize требует очистки кэша при правках CSS.
2. **`hotfix.css` перебивает `main.css`** — проверять первым.
3. **Версии в `inc/enqueue.php`** — если правки не видны, проверь первым.
... (пункты 4–56 без изменений, см. v15) ...
57. **Rank Math: `wp-sitemap.xml` отдает 301 на `sitemap_index.xml`** — это нормальное поведение плагина.
58. **Если `sitemap_index.xml` не обновляется**, добавить в `functions.php`: `add_filter( 'rank_math/sitemap/enable_caching', '__return_false' );`
59. **Если `jquery-migrate` возвращается**, проверить плагины. Лечится добавлением `wp_deregister_script( 'jquery-migrate' )` в `functions.php`.
60. **Autoptimize:** НЕ включать опцию «Также оптимизировать админку», иначе сломается редактор Gutenberg. При проблемах с версткой — очистить кэш Autoptimize или снять галочку «Устранить CSS, блокирующий рендеринг» (Critical CSS).
61. **Метрика:** НЕ активировать плагин WP Yandex Metrika обратно, иначе будет дубль счётчика (один в `head`, второй в `footer`). Код в `footer.php` править вручную.
62. **Карты:** В `template-parts/map.php` и `page-contacts.php` iframe карт теперь используют `data-src` вместо `src`. Скрипт `lazy-map.js` подгружает их при скролле. Если карта перестала грузиться — проверить консоль и `lazy-map.js`.
63. **`functions.php`:** В нем висят критичные фиксы (preload, defer, отключение эмодзи, jquery-migrate). При обновлении темы — сохранить их.
64. **Rank Math Focus Keywords:** Для 13 страниц заданы вручную. Не сбрасывать.
